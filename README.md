# Hill Traffic Runner

3D endless traffic-dodging game set in the hills. Built with Godot 4.3 —
all art is procedural (no imported assets).

**v0.1 test build:** 3 lanes, swipe or tap left/right side to change lanes,
dodge cars and trucks on a winding hill road, near-miss bonus (+25),
speed rises over time, best score saved on device.

GitHub Actions builds a debug-signed test APK on every push
(artifact: `HillTrafficRunner-test-apk`).
